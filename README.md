# 한국어 자막 스튜디오

한국어 SRT 자막을 WebVTT로 일괄 변환하는 독립 Windows 데스크톱 앱입니다.

## 기능

- SRT 파일 다중 선택 및 드래그 앤 드롭
- UTF-8, UTF-16, CP949 입력 자동 판별
- 국내 LMS와 Windows 앱 호환을 위한 UTF-8 BOM 출력
- 초 단위 자막 시간 보정
- 원본 폴더 또는 `VTT` 하위 폴더 저장
- 기존 파일 덮어쓰기 선택
- 파일별 변환 결과와 오류 표시

## 실행

`배포/한국어_자막_스튜디오.exe`를 실행합니다. 별도 설치가 필요하지 않습니다.

## 빌드

Windows에서 `빌드.bat`을 실행합니다. .NET Framework 4.x가 필요합니다.
